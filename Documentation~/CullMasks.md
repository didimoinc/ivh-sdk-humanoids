# Cull Masks

`URP_LitWithCulls`, the shader used on `ddmo_body_MAT` and `ddmo_head_MAT`, uses a cull mask
texture to hide the parts of the body mesh that sit under an outfit. This page lists where the
masks live and which combination goes with which outfit.

## Where to find them

- Characters generated by Didimo's Character Generation Service ship their own cull masks under
  `deformables/<deformable name>/*_cullmask.png`.
- A copy of every cull mask used in this package is also collected under
  `Runtime/Textures/CullMasks`, for convenience.

There are two cull masks per character geometry, head and body, and per gender (`_m_` for male,
`_f_` for female).
